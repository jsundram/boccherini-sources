## Two caveats

**The publisher is not RISM's word.** RISM's `260` carries only the date, `[1769]` — no place
and no publisher. Venier/Paris comes from the hand identification of the title page.

**"Opera VI" is the publisher's number.** **Op. 8** is the normalized modern number the Gérard
catalogue uses for these six works — the same divergence as the Bremner *opera X* print
(Op. 9) and the Hummel *opera prima* (Op. 2).
