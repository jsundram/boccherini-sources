## How this was identified

Identified by hand from the title page (see `opus 8 - london edition (bremner) - G165-170.md`).
RISM [**990005859**](https://rism.online/sources/990005859) is the same print — *"Six
quartettos [c, D, E♭, g, F, A] for two violins, tenor and violoncello … opera VI [London,
R. Bremner]"* — and records the E-Mn copy at `M/680-683`. The six keys match the Venier
print of the same works (RISM 990005861, `D, c, E♭, g, F, A`).

RISM does **not** link BNE's scan.

## `M/680-683` holds two sets, not one

RISM files two Bremner prints at this one shelfmark range, and both are real — the four
part-books carry both volumes bound together:

| | Bremner's number | Gérard | filed at |
|---|---|---|---|
| libro secondo | *opera VI* | **Op. 8, G 165–170** | this folder |
| libro terzo | *opera X* | **Op. 9, G 171–176** | `../../G171-176/bne-9ecb259b-abc` |

So a shelfmark match to `M/680-683` does not by itself say which set is meant.

## "Opera VI" is the publisher's number

**Op. 8** is the normalized modern number the Gérard catalogue uses. Bremner numbered this
set VI and the next one X — the same divergence already seen in the Hummel *opera prima*
(Op. 2) and Bremner's own *opera X* (Op. 9).
