# Op. 54, 1796 (US-Wc, `M452.A2 B68 op. 54 Case`)

> *Opera 54 … 1796 … **Tre Quartetti** Per due Violini, Viola e Basso*
> *Composti del Sig. Luigi Boccherini … Violino Primo*

`US-Wc_M452-A2-B68-op54.pdf` — 85 pages, 469 MB. **Official scan commissioned from the
Library of Congress.**

## Two things are unresolved — read before trusting the folder name

**The count.** The folder is named for G 250–255, six quartets, from the earlier pass's
filename *"Opus 54 Numbers 1-6"*. The title page says **Tre Quartetti** — three. Nothing
examined so far settles which is right.

**RISM does not know these numbers.** No GerB number from 250 upward appears in any
harvested RISM record. The highest in the corpus is 249. So this set is outside the
catalogue this project is built on, and `UNLINKED-HOLDINGS.md` will never list it.

Sampled pages (24, 44, 64) are single-line part music with works ending mid-volume, so
this is a **part-book**, not a score — the title page names *Violino Primo*. Whether the
other three parts were scanned is not established here.
