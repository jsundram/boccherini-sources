## How this was identified

BNE does not state a Gérard number. RISM [**990005852**](https://rism.online/sources/990005852)
is the same Hummel edition (GerB 159–164) and lists an E-Mn holding at
[`M/684-687`](https://rism.online/holdings/23733) — the four part shelfmarks match exactly.
RISM does **not** link BNE's scan, so this copy arrived outside the harvester.

- **Open at BNE:** <https://bnedigital.bne.es/bd/es/viewer?id=42b0a27a-b248-4248-8d6e-8088f953322f&page=1>
- **BNE record:** <https://bnedigital.bne.es/bd/es/card?id=42b0a27a-b248-4248-8d6e-8088f953322f>

## Note on the opus number

The title page says *opera prima*. **Op. 2** is the normalized modern number used in the
Gérard catalogue for these six works — the same publisher-vs-Gérard divergence seen in the
Bremner Op. 9 print, which its title page calls *opera X*.
