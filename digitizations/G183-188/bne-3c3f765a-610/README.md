# Sei quartetti … opera XXVI — the Le Duc issue

Printed edition from BNE Digital. **Not linked by RISM.**

- **Gérard:** G 183–188 (Op. 22, 1775)
- **Printed opus:** **XXVI**, the publisher's number; *Op. 22* is Gérard's
- **Publisher:** Le Duc, Paris (c. 1800)
- **Identified by hand from the scan, 2026-09-28**

RISM catalogues this issue as [990005875](https://rism.online/sources/990005875) and records an E-Mn copy at `Mp/2392|9` — very likely this one.

The same edition appears earlier under **La Chevardière** as [990005874](https://rism.online/sources/990005874), so the two records document the Paris succession La Chevardière → Le Duc → Imbault.
